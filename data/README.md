# Data

`indicators.csv` holds one row per observation; `metadata.json` holds source, unit and method per indicator.

Confidence flags: `verified` = matches a Nepal Rastra Bank release; `approximate` = compiled from memory of published releases and **must be checked** against the linked portal before citing. Replace values from the NSO / NRB portals and keep the same columns.

Blank values are treated as missing (never as zero).

Data
indicators.csv holds one row per observation; metadata.json holds source, unit and method per indicator.

Confidence flags:

verified: the value is stated in an NRB or NSO release.
derived: back-calculated from a growth rate reported in a release (method in metadata.json).
approximate: compiled from memory, not yet checked; verify before citing. Replace values from the NSO / NRB portals and keep the same columns.
Blank values are treated as missing (never as zero).
